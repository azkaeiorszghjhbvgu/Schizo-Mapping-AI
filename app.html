Search Mechanics

01 / Uniform-Cost Search (UCS)

Type: Blind Search

UCS explores paths in increasing order of their actual path cost $g(n)$. It guarantees finding the optimal (shortest) path on weighted graphs because it always expands the cheapest node in the frontier.

02 / A* Search (Fruit Fly Scent)

Type: Heuristic Search (Bio-Inspired)

A* guides the search using an estimate, $f(n) = g(n) + h(n)$. Our custom heuristic simulates fruit fly scent tracking: the scent estimate is straight-line distance, discounted 15% when the goal lies downwind (west → east). The discount only lowers the estimate, so it never overestimates and A* stays optimal. The trade-off is a slightly weaker guide: across all 380 city pairs, Fruit Fly A* expands 2,759 nodes vs 2,647 for plain straight-line A*, still 34% fewer than UCS (4,180).
