Search Mechanics

01 / Uniform-Cost Search (UCS)

Type: Blind Search

UCS explores paths in increasing order of their actual path cost $g(n)$. It guarantees finding the optimal (shortest) path on weighted graphs because it always expands the cheapest node in the frontier.

02 / A* Search (Fruit Fly Scent)

Type: Heuristic Search (Bio-Inspired)

A* guides the search using a smart estimate ($f(n) = g(n) + h(n)$). Our custom heuristic simulates fruit fly scent tracking, applying a 15% discount for movement along prevailing west-to-east wind directions to speed up the search while staying optimal.
